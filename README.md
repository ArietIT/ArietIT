- 🐍 Junior Python Backend Developer из Кыргызстана
- 🏗️ Специализируюсь на **Django**, REST API и серверной логике
- 🤖 Разрабатываю AI-сервисы — сейчас работаю над **[KyrgyzAI](https://github.com/ArietIT/KyrgyzAI)**, чатом на Gemini API для кыргызского языка
